## 해결하려는 문제
매장은 판매 변화에 맞춰 식자재를 준비하면서 재고 부족·과잉·폐기를 함께 관리해야 하고, 발주할 때 현재고뿐 아니라 사용기한, 입고 예정 물량, 공급사별 발주 요일·마감·리드타임·최소 발주금액까지 따져야 한다.

## 주요 기능
1. **대시보드** — 부족 예상(긴급)·오늘 발주할 공급사·사용기한 임박·과잉 재고 알림, 다가오는 발주 일정
2. **발주 추천** — 공급사·발주일별 발주서, 품목별 추천 수량(발주단위)·금액, 최소 발주금액 충족 여부
   - 행을 누르면 계산 근거(발주 시점, 책임 기간, 예측 소요, 안전재고, 단위 환산, 단가, 일별 재고 흐름)
   - 수량을 직접 고치면 예상 재고·금액·최소금액 판정이 즉시 재계산
   - 발주안 저장 / 확정(모의 전송)
3. **재고·사용기한** — 식자재별 실제 재고 추이 + 예상 재고, 입고 묶음별 잔량·남은 사용일
4. **가정·근거** — 적용한 가정과 데이터 해석, 한계
5. **조건 설정**(모든 화면 공통) — 매장, 기준일, 현재 시각, 수요 조정 %, 예측 기준 기간, 안전재고, 입고 지연 대비, 임박·과잉 기준, 프로모션 반영

## 사용 방법
1. 왼쪽에서 매장을 고른다. 기준일은 데이터 마지막 날 다음 날(2026-10-01)로 설정되어 있다.
2. 대시보드에서 긴급 알림과 오늘 발주할 공급사를 확인한다.
3. 발주 추천에서 품목별 근거를 확인하고 필요하면 수량을 고친 뒤 저장/확정한다.
4. 수요 조정·안전재고 등을 바꿔 결과가 어떻게 달라지는지 비교한다.
5. 기준일을 과거로 바꾸면 당시 추천을 실제 결과와 비교해 볼 수 있다.
